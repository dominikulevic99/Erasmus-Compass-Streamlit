# Erasmus-Compass-Streamlit
Erasmus Compass is a Python-based decision-support tool designed to help students evaluate whether participating in the Erasmus exchange programme is the right decision for them.

The project combines elements of decision analysis, expected utility theory, and personalised weighting systems to transform subjective feelings into a structured evaluation process. Instead of providing a simple “yes” or “no” answer, the program analyses multiple dimensions of the decision and generates a personalised recommendation based on the user’s priorities and self-assessment.

The system evaluates four primary dimensions:

Personal achievement development Financial readiness Risk resilience Psychological readiness Users respond to a structured survey using a 1–5 agreement scale. Afterwards, they assign personal priority weights to each decision dimension, where the total weight must equal 100. The program then calculates an Expected Utility score representing the overall value of the Erasmus experience for that specific user profile.

In addition to the mathematical evaluation, Erasmus Compass includes a rule-based interpretation engine that analyses relationships between user priorities and evaluation scores. This allows the program to generate personalised insights, identify potential internal conflicts, and highlight the strongest and weakest aspects of the decision.

The project was developed in Python without external libraries and focuses on:

user-centred decision modelling, weighted utility calculations, structured survey systems, conditional logic, and personalised analysis generation. Erasmus Compass demonstrates how programming can be applied to real-life decision-making problems by combining technical logic with behavioural and psychological considerations.
